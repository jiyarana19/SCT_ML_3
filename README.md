# Cats vs Dogs Image Classification using SVM

This project is completed as part of the Machine Learning Internship at SkillCraft Technology.

## Objective
To classify images of cats and dogs using Support Vector Machine (SVM).
## Dataset
Kaggle Cats and Dogs Dataset:
https://www.kaggle.com/datasets/salader/dogs-vs-cats

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib
- Scikit-learn

## Steps Performed
1. Image Loading
2. Image Resizing
3. Feature Extraction
4. Train-Test Split
5. SVM Model Training
6. Prediction and Evaluation
7. Visualization

## Output
The model predicts whether an image is a cat or dog and displays prediction results.
